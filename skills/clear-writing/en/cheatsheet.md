# Choose an editing action

Use for a disputed edit. The topic chapters explain the reasoning.

| If | Do this | Because |
| --- | --- | --- |
| The text is short but unclear | Add the missing explanation or example | Length does not measure clarity |
| The text is long but every detail matters | Add a short entry point and navigation | Readers need access to meaning, not lost information |
| People do not open the text | Check the subject, channel, and expectations | Rewording cannot fix the wrong context |
| The reader knows the term | Keep the exact name | An arbitrary synonym creates a new referent |
| The reader does not know the term | Explain it at its first necessary use | Removing the term may destroy precision |
| An evaluation lacks support | Find evidence in the sources or remove it | A plausible fact does not become real |
| A fact means nothing to the reader | Add a comparable scale or scenario | A number without a frame of reference may remain abstract |
| A qualification changes certainty or a condition | Keep it and make it visible | Simplification must not strengthen a claim |
| The actor is unknown or irrelevant | Keep the focus on the event or state | Active voice does not justify invention |
| Splitting sentences makes the text choppy | Restore connections and sentence variety | Short sentences can be difficult too |
| A mistaken application is likely | Add a short counterexample and explain the boundary | A correct example may not be enough |
| An analogy creates false expectations | State its limits or replace it with a direct example | Similarity does not establish identical properties |
| The reader is comparing options | Use the same criteria for each | This exposes differences that matter to the decision |
| The reader acts while reading the steps | Put prerequisites and preparation before the action | A missed step cannot be completed retroactively |
| The text cannot change | Improve navigation or add a separate explanation within the allowed scope | Mandatory wording remains intact |
| An illustration promises more than the text | Fix the impression, scale, or selection of data | A small caveat does not cancel a visual promise |
| A phrase already serves its purpose | Leave it | A new version is not necessarily better |

When priorities conflict, use this order: accuracy and contract → reader's task →
clarity → brevity and expressiveness. Apply a technique only when it improves the
text by these criteria.
