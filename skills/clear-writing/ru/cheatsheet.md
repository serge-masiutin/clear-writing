# Как выбрать редакторское действие

Используй для спорной правки. Обоснования находятся в тематических разделах.

| Если | Сделай | Потому что |
| --- | --- | --- |
| Текст короткий, но непонятный | Добавь недостающее объяснение или пример | Длина не измеряет ясность |
| Текст длинный, но каждая деталь нужна | Дай краткий вход и навигацию | Читателю нужен доступ к смыслу, а не потеря сведений |
| Текст не открывают | Проверь тему, канал и ожидания | Правка фраз не исправляет неподходящий контекст |
| Читатель знает термин | Сохрани точное название | Случайный синоним создаёт новый предмет |
| Читатель не знает термин | Объясни его при первом нужном употреблении | Удаление термина может разрушить точность |
| Оценка не подкреплена | Найди основание в источниках или убери оценку | Правдоподобный факт не становится реальным |
| Факт ничего не говорит читателю | Добавь сопоставимый масштаб или сценарий | Число без опоры может остаться абстракцией |
| Оговорка меняет уверенность или условие | Сохрани её и сделай заметной | Упрощение не должно усиливать утверждение |
| Исполнитель неизвестен или неважен | Сохрани фокус на событии или состоянии | Активный залог не оправдывает выдумку |
| После дробления текст звучит отрывисто | Восстанови связи и разнообразие фраз | Короткие предложения тоже бывают трудными |
| Есть вероятное ошибочное применение | Добавь короткий антипример и объясни границу | Правильного примера может быть недостаточно |
| Аналогия приносит ложные ожидания | Назови границу или замени её прямым примером | Сходство не доказывает одинаковые свойства |
| Читатель сравнивает варианты | Сопоставь их по одним критериям | Так видны различия, важные для выбора |
| Читатель выполняет шаги по мере чтения | Поставь условия и подготовку раньше действия | Он не может выполнить пропущенный шаг задним числом |
| Текст нельзя менять | Улучши навигацию или добавь отдельное пояснение в разрешённых пределах | Обязательная формулировка останется целой |
| Иллюстрация обещает больше текста | Исправь впечатление, масштаб или подбор данных | Мелкая оговорка не отменяет визуального обещания |
| Фраза уже решает задачу | Оставь её | Новая версия не обязана быть лучше |

При конфликте выбирай в таком порядке: точность и контракт → задача читателя →
понятность → краткость и выразительность. Применяй приём только тогда, когда он
улучшает текст по этим критериям.
