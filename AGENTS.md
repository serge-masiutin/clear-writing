# Clear Writing: работа в репозитории

- Отвечай пользователю и пиши проектную документацию по-русски. Сохраняй английский
  в английской версии скилла и общих переносимых контрактах; русский — в русской.
- Основной артефакт — `skills/clear-writing/`. Не меняй установленные копии в других
  проектах или пользовательских каталогах без отдельного запроса.
- Перед изменением прочитай `SKILL.md`, связанные руководства, тесты и
  `references/localization-review.md` внутри скилла. Сохраняй полные версии обоих языков.
- Технические профили — прикладные рекомендации, не сертификация ASD-STE100 или ГОСТ.
  Не выдавай локальные баллы и структурные тесты за проверку соответствия стандарту.
- После изменения запускай `bin/check`. При изменении инструкций отдельно проверяй
  поведение по `ru/references/review-cases.md` и `en/references/review-cases.md`.
  Указывай модель, случаи и ограничения; не называй самопроверку независимым запуском.

## Git и GitHub

- Используй только `bin/gh` под `serge-masiutin`; повторный вход — `bin/gh-login`.
- Настраивай личные Git identity, SSH и подпись через `bin/setup-git` только локально.
  Не меняй глобальные Git/SSH, Keychain или авторизацию других проектов.
- Credentials хранятся только в `gh/` общего Git-каталога: каталог `700`, файлы `600`.
  Не выводи их и не добавляй в коммиты. Подробности — `docs/development.md`.
