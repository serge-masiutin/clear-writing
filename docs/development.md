# Разработка скилла

Меняйте исходники в `skills/clear-writing/`. Установленные копии не обновляются
автоматически. Общие правила находятся в `AGENTS.md`, порядок языкового ревью —
в `skills/clear-writing/references/localization-review.md`.

## Проверки

```sh
bin/check
```

Нужны Python 3.9+, Ruby, Bash и Git. Команда запускает тесты локального анализатора,
проверяет комплектность языковых версий, локальные Markdown-ссылки, GitHub-обёртку
на изолированных фиктивных credentials и синтаксис скриптов. Она не проверяет
качество редактуры или соответствие ASD-STE100.

Для проверки поведения используйте задания из `references/review-cases.md` каждого
языка. Передавайте модели актуальный `SKILL.md` и выбранные руководства, а не только
название установленного скилла. Примеры технических заданий и порядок сравнения —
в [проверке технического профиля](technical-evaluation.md).

## GitHub CLI

Используйте `bin/gh`. Обёртка проверяет через API аккаунт `serge-masiutin` перед
каждым вызовом и задаёт репозиторий `serge-masiutin/clear-writing` по умолчанию.
Глобальная авторизация `gh`, настройки других проектов и Keychain не меняются.

```sh
bin/gh api user --jq .login
bin/gh pr list
```

Первый или повторный вход — `bin/gh-login`. Нужны Docker, curl, shasum, tar и браузер.
Скрипт загружает официальный Linux CLI 2.96.0, сверяет SHA-256 и запускает вход
во временном контейнере `ruby:4.0.7-slim` из примера `gold_ops`, без доступа
к домашнему каталогу.
При входе выберите `serge-masiutin`. Интерактивный сценарий требует отдельной
ручной проверки; синтаксические тесты не подтверждают вход через браузер.

Токен хранится открытым текстом только в `gh/hosts.yml` внутри общего Git-каталога:
каталог имеет права `700`, файлы — `600`. Связанные worktrees используют этот вход;
отдельный клон требует отдельной настройки. Не выводите и не коммитьте credentials.
Обёртка передаёт токен только дочернему CLI, сбрасывает внешние токены и debug-флаги.
Команды `auth`, кроме `auth status`, запрещены: обычный вход может затронуть Keychain.

Личные Git identity, SSH и подпись настройте отдельно:

```sh
bin/setup-git
```

Скрипт использует существующий ключ `~/.ssh/id_ed25519_serge_masiutin_gh` и меняет
только локальную Git-конфигурацию. Он не создаёт ключ, не меняет remote, не коммитит
и не отправляет изменения. Обёртки адаптированы из `serge-masiutin/gold_ops`.
